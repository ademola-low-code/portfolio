# Topic bank

Question-shaped topics for the blog. One per line.

- `- [ ]` = not written yet
- `- [x]` = already published

The pipeline takes the top unwritten topic each run, writes it, and ticks it off.
It also tops this list up automatically from the n8n community forum and Stack Exchange.

You can add your own topics any time — just add a line starting with `- [ ]`.
Topics you add by hand are used first.
